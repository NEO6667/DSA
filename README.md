# 📘 Personal DSA Practice Repository

Welcome to my personal Data Structures & Algorithms (DSA) practice repo!  
This repository is a collection of problems I solve regularly for revision, learning, and improvement. It contains my solutions to problems from platforms like **LeetCode**, **Codeforces**, **GeeksforGeeks**, and more.

---

Each folder contains:
- ✅ Problem solutions (in C++ mostly)
- 💡 Brief problem descriptions or links
- ✍️ Occasionally, my thought process or intuition behind the approach

---

## 🎯 Purpose

This repo serves **as a personal reference and revision notebook**. I'm not focused on polished code or writeups, but rather on:
- Practicing core patterns (sliding window, two pointers, recursion, etc.)
- Tracking progress over time
- Reinforcing my understanding by re-solving old problems

---

## 🧠 Topics Covered

- Arrays & Strings
- Sorting & Searching
- Linked Lists
- Trees & Binary Trees
- Binary Search Trees
- Recursion & Backtracking
- Greedy Algorithms
- Dynamic Programming
- Graphs (DFS, BFS, Dijkstra)
- Tries, Heaps, Hashmaps, etc.

---

## 🛠 Languages Used

- **C++** (main)
- May include some Python/Java as experiments

## 📝 Notes

- This is not a tutorial repo.
